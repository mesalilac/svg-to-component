Convert svg icon into SolidJS components

## Run

```sh
uv run main.py -i /path/to/source/svg/icons -o /path/to/target/components/icons
```

## Help message

```
Usage: main.py [OPTIONS]

Options:
    -i, --input-dir DIRECTORY   Path to directory containing SVG files
                                [required]
    -o, --output-dir DIRECTORY  Path to directory to output component files
                                [required]
    -x, --no-index-ts           Don't generate a index.ts file
    -h, --header TEXT           String to prepend to generated files
    -f, --force                 Force overwrite existing files
    -v, --verbose               Enable verbose output
    --help                      Show this message and exit.
```
